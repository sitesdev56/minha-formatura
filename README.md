🎓 Minha Formatura

Este projeto é um site de convite digital para formatura, criado para apresentar de forma simples, bonita e acessível todas as informações importantes do evento.

🔗 Acesse o site:
https://sitesdev56.github.io/minha-formatura/

📌 Sobre o projeto

O Minha Formatura é uma página web estática desenvolvida com HTML, CSS e JavaScript, pensada para ser visualizada tanto em computadores quanto em celulares.

O objetivo do site é substituir convites físicos, facilitando o compartilhamento das informações da formatura por meio de um link.

🎯 O que o site faz

Apresenta os dados principais da formatura

Informa data, horário e local do evento

Transmite uma mensagem inspiradora sobre o momento da formatura

Oferece um visual simples e elegante para convidados

Funciona diretamente no navegador, sem necessidade de instalação

🧩 O que o site contém

🎓 Título do evento (Formatura 2025)

📅 Data do evento

⏰ Horário da cerimônia

📍 Local da formatura

💬 Frase motivacional

📱 Layout responsivo, adaptado para celular

🌐 Hospedagem via GitHub Pages

🛠️ Tecnologias utilizadas

HTML5 — estrutura do site

CSS3 — estilização e layout

JavaScript — interações simples

GitHub Pages — hospedagem gratuita

🚀 Objetivo

Criar uma forma moderna, prática e digital de divulgar um momento especial, permitindo que amigos e familiares tenham acesso rápido às informações da formatura.
